# 线性代数 Cheat Sheet

一个现代化的线性代数速查表网站，涵盖核心概念、公式和性质。

## 功能特性

- **10 大主题模块**：向量、矩阵、矩阵运算、行列式、线性方程组、特征值与特征向量、向量空间、线性变换、正交性、矩阵分解
- **数学公式渲染**：基于 MathJax 的 LaTeX 公式支持
- **实时搜索**：输入关键词即可过滤内容，高亮匹配文本
- **暗黑模式**：支持浅色/深色主题切换，自动记忆偏好
- **侧边导航**：滚动时自动高亮当前章节，快速跳转
- **响应式设计**：适配桌面、平板和手机

## 在线预览

通过 GitHub Pages 查看：设置仓库 Settings → Pages → Source: main branch 即可。

## 本地运行

直接在浏览器中打开 `index.html`，或使用本地服务器：

```bash
# Python
python -m http.server 8000

# Node.js (需安装 http-server)
npx http-server
```

然后访问 `http://localhost:8000`。

## 项目结构

```
linear-algebra-cheatsheet/
├── index.html      # 主页面（含所有概念内容）
├── styles.css      # 样式表（主题、布局、响应式）
├── script.js       # 交互逻辑（搜索、暗黑模式、导航）
└── README.md       # 项目说明
```

## 涵盖内容

| 章节 | 内容 |
|------|------|
| 向量 | 定义、加减法、标量乘法、点积、叉积、范数、单位向量 |
| 矩阵 | 定义、特殊矩阵类型、单位矩阵 |
| 矩阵运算 | 加法、乘法、转置、逆矩阵、迹、秩 |
| 行列式 | 定义、性质、几何意义、伴随矩阵 |
| 线性方程组 | 矩阵形式、解的判定、高斯消元、克拉默法则、最小二乘 |
| 特征值与特征向量 | 定义、特征方程、性质、对角化、谱分解 |
| 向量空间 | 定义、子空间、线性无关、基与维数、四个基本子空间 |
| 线性变换 | 定义、矩阵表示、核与像、常见变换 |
| 正交性 | 内积空间、正交集、Gram-Schmidt、正交投影、正交补 |
| 矩阵分解 | LU、QR、特征值分解、SVD、Cholesky |

## 技术栈

- HTML5
- CSS3 (CSS 变量、Flexbox、Grid)
- 原生 JavaScript (无框架依赖)
- [MathJax 3](https://www.mathjax.org/) (数学公式渲染)
